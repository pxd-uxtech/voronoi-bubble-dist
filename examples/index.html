VoronoiBubble 예제

npm run build 후 npm run dev로 띄운 뒤 아래 예제를 여세요.

  • Basic 가장 기본적인 렌더 — 제목·캡션·그룹 라벨·퍼센트 표시.
  • Sentiment sentiment 옵션으로 1~5 점수 필드를 다이버징 컬러맵에 연결.
  • Custom Labels renderGroupLabel로 그룹 라벨을 직접 HTML로 그리기 (헤일로 + 퍼센트).
  • Popup & Hover onClick 팝업과 onHover 콜백 — 추가 CSS 없이 동작.
  • Simple Popup showVoronoiPopup만 사용한 최소 클릭 팝업 예제.
  • Playground 항목 수·캔버스 크기·fontScale을 슬라이더로 바꿔가며 폰트 정규화 확인.
