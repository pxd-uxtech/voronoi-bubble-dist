VoronoiBubble Examples

Run npm run build, then npm run dev, and open one of these examples.

  • Basic Basic tidy rows -> Voronoi treemap rendering with title, caption, group labels, and percentages.
  • Customer Feedback Topics The flagship qualitative-data use case — review topics sized by mentions, with click popups quoting each opinion.
  • Book Taxonomy A catalog taxonomy (section -> genre -> title) using levels/value to keep original column names.
  • Sentiment Map a 1-5 rating field to the built-in red-yellow-green sentiment colormap.
  • Semantic Positions Use positions to add UMAP-like placement to a Voronoi treemap.
  • Budget Map Prepared hierarchy example: departments, programs, projects, and budgets.
  • Palette Presets Use colors: "waterLilies" and other built-in palette strings.
  • Custom Labels Render group labels with custom HTML.
  • Popup & Hover Use onClick popups and onHover callbacks.
  • Simple Popup A minimal click popup example using showVoronoiPopup.
  • Playground Adjust item count, canvas size, and fontScale interactively.
